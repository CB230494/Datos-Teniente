## Publicación en GitHub Pages
1. Cree un repositorio nuevo en GitHub.
2. Suba `index.html`, `styles.css` y `script.js` a la raíz.
3. Entre en Settings → Pages.
4. En Source seleccione `Deploy from a branch`.
5. Seleccione la rama `main` y la carpeta `/ (root)`.
6. Guarde y espere la publicación.

Los valores pueden modificarse en el arreglo `risks` dentro de `script.js`.
